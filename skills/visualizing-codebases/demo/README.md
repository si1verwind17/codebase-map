# Demo: parking-city (code-map showcase)

> **For human readers only.** This directory is a showcase of what the
> `visualizing-codebases` skill produces. It is NOT reference material for
> agents. Agents running `visualizing-codebases` must not read, copy or
> imitate anything here. The map for the user's repository comes from that
> repository's committed code, through the skill's own rules.

- [`parking-city/`](parking-city/) is a fictional city parking network,
  written as illustrative code. Its code map is at
  `parking-city/docs/viz-code/code-map.json`, and the prebuilt viewer page is
  at `parking-city/docs/viz-code/index.html`. See its own
  [README](parking-city/README.md).
